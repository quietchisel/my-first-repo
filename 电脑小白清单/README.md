# 电脑小白清单（生成器）

桌面那个「电脑小白清单」文件夹不是手工拖出来的，是这套脚本生成的。

## 换电脑 / 重建的步骤

1. 把 `入口清单.sample.json` 复制成 `入口清单.json`
2. 打开它，把每条 `target` 里的 `<你的工作区>` 换成你本机的真实路径（文件不存在的那条会自动跳过并在窗口里报出来）
3. 双击 `建桌面入口.bat`
4. 桌面出现 `电脑小白清单` 文件夹，里面是按「什么时候点」命名的快捷方式

## 为什么这么设计

- **入口清单.json 是唯一数据源**：加/删/改名只改这个 JSON，不手工拖快捷方式（手工的会被下次重跑覆盖）
- **建桌面入口.ps1 是纯 ASCII**：避免 PowerShell 按 GBK 解析 UTF-8 中文时把字符串搞乱（踩过）
- **`.ps1` 存 UTF-8 带 BOM**：同上，这是 Windows PowerShell 的硬要求
- **真实 `入口清单.json` 不进仓库**：它含本机绝对路径，没必要公开

## 命名规则

图标名 = `① 什么时候点 · 干什么`。前半截是场景，后半截是动作——**看到名字就知道要不要点，不用记**。
