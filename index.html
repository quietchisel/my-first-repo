任务栏优化（窗口开太多太挤） 7 条

只留图标、不显示窗口标题
设置 → 个性化 → 任务栏 → 「任务栏行为」→「合并任务栏按钮并隐藏标签」→ 选「始终」
为什么会显示全名
这一项现在是「从不」= 每个窗口都摊开「图标 + 完整标题」
想更省地方
同一页里：搜索框改成「仅图标」、关掉「小组件」按钮
同一程序开了多个窗口
合并后点图标会弹出全部窗口缩略图，窗口一个都不会丢
快速切到任务栏第 N 个图标
Win+1 到 Win+9（从左边数）
所有窗口一览
Win+Tab（任务视图）
想恢复原样
把「合并任务栏按钮并隐藏标签」改回「从不」
注册表位置（不用记，知道有这回事即可）：
HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced 里的 TaskbarGlomLevel
—— 0 = 始终合并（只留图标）／1 = 任务栏满时合并／2 = 从不合并（图标+标题）

GitHub 与代码托管 13 条

建新仓库（最快）
地址栏直接输 github.com/new
下载别人的项目（不装软件）
项目页 → 绿色 Code 按钮 → Download ZIP
在网页上改文件
打开文件 → 右上角铅笔图标 → 改完点 Commit changes
判断项目靠不靠谱
看 Star 数、最后更新时间、README 有没有写清楚
看某个文件的历史版本
文件页 → 右上 History
找回被删掉的文件
仓库页 → Commits 里翻到删除前的那次提交
想存私有项目
建仓库时选 Private，只有自己可见
加速访问（国内）
换网络环境最有效；镜像站只能下代码，不能提交
GitHub 搜仓库
顶部搜索框输 in:name 软件名，直接命中仓库名
组合筛选
topic:windows stars:>500 pushed:>2025-01-01（主题 + 星数下限 + 最近有提交）
找教程合集
in:readme 关键词，搜 README 正文
识别废弃项目
结果带 Public archive 标签 = 已废弃，直接跳过
挑仓库四步法
README 看得懂 → 半年内有提交 → Issue 有人回 → Star 在同类里什么水平，30 秒出结果
一条铁律：密码、API 密钥、身份证照片永远不放进仓库。公开仓库全世界可见，还有爬虫 7×24 扫。
Git 和 GitHub 不是一回事：Git 是装在本机的版本管理软件（已装，2.55.0），GitHub 是网上的托管网站。小白阶段网页操作足够，不用碰命令行。
