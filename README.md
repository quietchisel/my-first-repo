## 为什么不放 my-first-repo

`my-first-repo` 是**公开**的（GitHub Pages 免费版要求公开），这个仓库是 **Private**，专门放不适合公开的内容。

## 备份策略

- **本地原始文件**：`D:\Deepseek Harness总文件夹\暂时性任务\_归档\20261027\`
- **云端副本**：这里
- 两边不一致时，**以本地为准**（本地是工作副本，云端是备份）

## 更新方式

两种：

1. **网页拖拽**（简单，适合偶尔备份）—— GitHub 页面点 `Add file` → `Upload files`
2. **git push**（标准，适合经常改）—— 本地建 git 仓库，改完推上来

区别：网页上传只产生一次云端提交，本地没有 git 记录；git push 两边都有记录，能回滚。

## 注意

- 单个文件上限 25 MB（网页上传）
- 私钥、密码、2FA 恢复码**永远不放这里**
